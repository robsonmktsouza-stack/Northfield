# Política de reporte de vulnerabilidades

Não divulgue chaves, XMLs de clientes ou dados sensíveis em issues públicos. Na instalação própria, reporte de forma privada ao mantenedor responsável pelo repositório; configure um canal de contato antes de anunciar o serviço ao público.

Itens críticos: vazamento de dados fiscais, API sem limitação de uso, XML inseguro, importação maliciosa de backups e acesso indevido a arquivos internos.
