# Como contribuir

1. Abra issue descrevendo a dor ou a regra proposta.
2. Para alteração fiscal, inclua norma, artigo, vigência, cenário, memória de cálculo e, se possível, comparação comprovada contra o sistema oficial.
3. Adicione testes das faixas, limites e casos negativos; bloqueie exceções ainda não cobertas.
4. Evite dados pessoais ou informações fiscais reais em commits, exemplos, issues, logs e testes.
5. Submeta pull request com explicação de alteração e impactos retroativos.
6. Não envie tokens, senhas, arquivos XML reais ou credenciais de contribuintes.
